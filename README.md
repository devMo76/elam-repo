# Elam

Arabic, right-to-left course platform built with Next.js App Router.

## Local development

1. Use Node.js `22.17.1` (see `.nvmrc` and `.node-version`).
2. Install dependencies with `npm install`.
3. Start the development server with `npm run dev`.
4. Open `http://localhost:3000`.

## Verification

- `npm run typecheck`
- `npm run lint`
- `npm run build`

Supabase, payments, video, email, and deployment configuration will be added in their corresponding milestones after the outstanding provider decisions are resolved.
